## How to use
- Start a task: `/recall PROJ-1234` in Copilot chat
- End a task: `/log`
- Weekly: `/connect` to fix missing links
- Save a ticket or Confluence page: `/capture` and paste it

## Folders
- Daily: one note per day, the timeline
- Tickets: one note per Jira ticket
- Projects: one note per project or service
- Knowledge: Confluence summaries and how-tos
- Decisions: why things were done a certain way
- People: colleagues
- Inbox: anything unsorted
