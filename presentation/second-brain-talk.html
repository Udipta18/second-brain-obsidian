Giving our AI a memory

Second Brain

Copilot chats forget everything. Our brains don't. Here's how I borrowed the brain's trick.

Udipta, October 2026

02

Our AI has goldfish memory

Every new Copilot chat starts from zero. Close the tab, and everything it learned about our ticket is gone.

Fun fact: real goldfish remember things for months. Our chats don't last past the tab.

03

JiraWhat to do, never what we tried
Teams chatAnswers buried in long threads
ConfluenceHow-tos we search for again and again

04

Honestly? I'm bad at keeping notes.

Docs go stale. Notes never get written. The same fix gets rediscovered next sprint.
So the system has to do the writing for me.

05

Remembering is following a connection

"Neurons that fire together, wire together."The short version of Hebbian learning

Things that come up together get linked. The more we use a link, the stronger it gets.

06

Obsidian works the same way

Neuron→a note
Synapse→a [[link]]
Recall→follow the links
Sleep→weekly clean-up that wires related notes

07

Copilot reads it before, writes it after

Copilot chat

Where we already work. Agent mode with a Claude model.

→
Second-brain skill

A text file of rules: when to read the notes, how to write and link them.

→
Obsidian vault

Plain notes on my laptop: tickets, docs, decisions, days.

Before a task it reads. After a task it writes. Nothing to remember by hand.

08

Four commands, four brain jobs

See/capture

Paste a Jira ticket or Confluence page. It becomes a linked note.

Recall/recall

Start a ticket with a briefing of everything we already know.

Store/log

End of task: what we did, why, and what's next, saved and linked.

Wire/connect

Once a week: links related notes, like the brain does in sleep.
